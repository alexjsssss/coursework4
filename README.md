# 🚗 Автомийка самообслуговування "Чисто"

**Автоматизована інформаційна система для організації роботи автомийки самообслуговування.**

🎓 Курсовий проєкт, розроблений із використанням C#, ASP.NET Core MVC та PostgreSQL.

---

## 📖 Опис проєкту

**«Чисто»** — вебзастосунок для автоматизації процесу замовлення послуг автомийки самообслуговування. Система забезпечує зберігання інформації про клієнтів, послуги, мийні бокси, замовлення та платежі.

Вебзастосунок передбачає два типи користувачів: **клієнт** та **адміністратор**, кожен із яких має власні функціональні можливості.

## ⚙️ Функціональні можливості

### 👤 Кабінет клієнта

- 🔐 Реєстрація та авторизація.
- 📊 Перегляд особистої статистики.
- 🚿 Перегляд доступних послуг та мийних боксів.
- 🛒 Вибір послуг і створення замовлення.
- 💳 Перехід до оплати та підтвердження замовлення.
- 📋 Перегляд історії замовлень.
- ✏️ Редагування особистих даних та зміна пароля.
- 🌗 Перемикання світлої й темної теми інтерфейсу.

### 🛠️ Панель адміністратора

- 📈 Перегляд основних показників роботи автомийки.
- 📦 Керування замовленнями.
- 🧽 Додавання, редагування та видалення послуг.
- 🚿 Керування доступністю мийних боксів.
- 💰 Перегляд інформації про доходи та замовлення.

## 📥 Встановлення та запуск

1. Завантажити вихідний код проєкту з GitHub.
2. Встановити необхідну версію .NET та PostgreSQL.
3. Створити базу даних `CarWashDB` і підготувати її таблиці.
4. Налаштувати підключення до PostgreSQL.
5. Відкрити проєкт у Visual Studio 2022.
6. Запустити вебзастосунок у браузері.
